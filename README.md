# Task Manager - Node.js

## Descripción del Proyecto

Este proyecto es un gestor de tareas que funciona desde la consola usando Node.js.
Permite agregar y mostrar tareas de manera sencilla.

- El proyecto tiene dos versiones:

- Primera versión: funcionalidad básica.
  
Este proyecto está diseñado para practicar:

- Uso de Node.js
- Manejo de módulos (`module.exports`)
- Estructuras condicionales
- Funciones
- Organización de código
- Buenas prácticas básicas

---

## Tecnologías Utilizadas

- Node.js
- JavaScript
- Módulo `readline` (para interacción en consola)

- Estructura del proyecto

Gestor de tareas/
│
├── Primera version/
│ └── index.js
│

  └── index.js
